## 功能

- 桌面秀展示（265x475 无边框窗口）
- 换装系统（发型、服装、配饰、翅膀等 20+ 分类）
- 拖拽移动
- 系统托盘常驻
- 本地素材，无需联网

## 开始使用

1. 下载 release 或 clone 本仓库
2. 安装依赖：
   ```bash
   npm install
   ```
3. 启动：
   ```bash
   npm start
   ```

## 构建

```bash
npm run build
```

输出在 `dist/` 目录。

## 技术栈

- Electron 28
- HTML/CSS/JS
- 无框架依赖
